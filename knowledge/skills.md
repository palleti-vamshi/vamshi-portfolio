# Technical Skills & Competencies

The technical skills below represent tools, languages, and frameworks actively verified across Palleti Vamshi's codebase implementations, course curricula, and project architectures.

## Programming Languages

- **C++**: Primary language used for algorithmic problem solving, Data Structures & Algorithms, and competitive programming.
- **Python**: Primary language used for Machine Learning modeling, digital twin simulations, data preprocessing, and automation utilities.
- **JavaScript (ES6+)**: Used for frontend applications and asynchronous Node.js backend services.
- **Java (Java 21 LTS)**: Used for enterprise backend architecture with Spring Boot and Spring Data JPA.
- **C**: Foundational procedural programming and systems concepts.

## Artificial Intelligence & Machine Learning

- **Machine Learning Foundations**: Supervised and unsupervised classification, feature selection, data preprocessing, and model evaluation metrics.
- **Scikit-Learn**: Implementation of baseline machine learning models including Random Forest, Decision Tree, and Logistic Regression.
- **XGBoost**: Gradient boosted decision tree classifiers applied to intrusion detection and tabular telemetry classification.
- **Explainable AI (XAI) Concepts**: Architectural design and feature importance analysis (such as planned SHAP attribution in the LightX-IDS research pipeline).

## Backend & Frameworks

- **Spring Boot (Spring Boot 4.x / 3.x)**: Enterprise application framework, layered architectures, dependency injection, and REST endpoints.
- **Spring Security (7.x)**: Authentication foundations, BCrypt credential hashing, and role-based access control.
- **Node.js**: Asynchronous JavaScript runtime for decoupled backend services and REST APIs.
- **Express (Express 5.x)**: Minimalist routing, custom middleware pipelines, cookie parsing, and CORS control.
- **FastAPI**: Lightweight asynchronous Python framework designated in the LightX-IDS serving roadmap.

## Databases & Persistence

- **MySQL (MySQL 8.x)**: Relational database design adhering to Third Normal Form (3NF), composite constraints, foreign keys, and analytical queries.
- **Spring Data JPA & Hibernate**: Object-relational mapping, entity lifecycles, and repository abstraction.
- **MongoDB**: Document-oriented NoSQL database for flexible data persistence.
- **Mongoose (Mongoose 9.x)**: Schema definitions, validation rules, and connection lifecycle management in Node.js.
- **H2 Database**: In-memory relational database used for automated persistence integration testing.

## Protocols, Systems & Messaging

- **MQTT (Mosquitto & Paho MQTT)**: Lightweight publish-subscribe messaging protocol used for real-time sensor telemetry streaming in industrial IoT architectures.

## Problem Solving & Theoretical Computer Science

- **Data Structures & Algorithms (DSA)**: Arrays, linked lists, trees, graphs, sorting, searching, hashing, and dynamic programming.
- **Complexity Analysis**: Big-O time and space complexity evaluation and practical memory considerations.
- **Competitive Programming**: Algorithmic problem solving across LeetCode, CodeChef, and Codeforces platforms.

## Development & Build Tooling

- **Git & GitHub**: Distributed version control, branch management, and repository maintenance.
- **Apache Maven & Maven Wrapper**: Dependency management and lifecycle builds for Java applications.
- **Vite**: Modern frontend build orchestration and development server tooling.
- **Linux CLI / Bash**: Shell navigation, file system operations, and process execution.
