# Technical Interests & Areas of Focus

Palleti Vamshi's technical interests center on foundational computing principles, algorithmic rigor, and the engineering of scalable, reliable software systems.

## 1. Artificial Intelligence & Machine Learning (AI / ML)
- Deep interest in machine learning theory, supervised and unsupervised classification, and feature engineering.
- Special interest in Explainable AI (XAI) and interpreting model decisions for safety-critical domains such as industrial cyber-physical systems.

## 2. Data Structures & Algorithms (DSA)
- Systematic study of computational complexity, tree and graph algorithms, recursion, dynamic programming, and space-time trade-offs.

## 3. Competitive Programming
- Contest-driven algorithmic problem solving, developing quick pattern recognition, edge-case analysis, and memory-conscious implementations in C++.

## 4. Emerging Technologies & Edge Intelligence
- Exploration of low-latency telemetry pipelines, edge computing for Internet of Things (IoT), and lightweight intrusion detection architectures.

## 5. Full-Stack Development & Distributed Systems
- Building robust, decoupled web applications using React on the frontend and Spring Boot or Node.js on the backend.
- Designing enterprise-grade database schemas, REST APIs, and authentication flows.

## 6. Engineering Problem Solving
- Applying structured methodology: Observe constraints → Define bottlenecks → Explore trade-offs → Build modular code → Test boundary cases → Iterate from feedback.
